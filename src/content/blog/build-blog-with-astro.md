## Preface

If you want a blog that loads lightning fast, is SEO friendly, and gives you full styling freedom, Astro is one of the best choices out there right now.

### Why Astro?

Traditional blog frameworks are either too heavy (Next.js) or have painful template syntax (Hugo). Astro hits a sweet spot in between.

If you build with React or Vue, a lot of JavaScript ships by default, which drags down page performance. Astro ships zero JS by default, so pages load extremely fast.

Of course, zero JS by default doesn't mean no JS at all. If you have a cool interactive component, Astro lets you load JavaScript for just that component.

### Deploying to GitHub Pages

This site was built with GLM 5.1 and deployed to GitHub Pages with the GitHub MCP. You just need to add a GitHub Actions workflow in the settings page — after that, every push automatically creates a deployment. That's it!

### Wrap-up

Astro + Tailwind CSS + MDX + GitHub Pages = a **free, fast, beautiful** personal blog.
