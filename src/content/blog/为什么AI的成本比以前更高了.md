最近有两个小变化引起了我的注意：DeepSeek 上调了 API 的价格，Codex 的 5 小时限制在暂时放开之后又要回来了。单看其中任何一个都不算大，但放在一起让我开始想一个问题：超级便宜的前沿智能，这个时代是不是快要结束了？

历史总在重复自己，类似的事情以前也发生过。2019 年 Uber 把这套逻辑写得很清楚，它在 2019 年的 S-1 招股书里明确描述了这一点：早期可以同时给司机和乘客补贴，司机和乘客变得越来越多，然后就会产生流动性网络效应——参与交换的人越多，交换就越容易发生，也就越能吸引更多人参与进来。

今天的 LLM，相当于处在 Uber 的早期到中期，还在补贴阶段，但价格已经涨上去了。所以 AI 套餐的用量看起来在变少，这可能是真的。把用户往更贵的套餐上推。如果未来我们见到 500 美元、1000 美元的 AI 套餐，我一点都不会意外，虽然我一点都不想看到这事发生。AI 可能正在走一条类似的补贴轨迹，这是第一个维度。

第二个维度是我们对 token 的消耗比以前更多了。过去我们只在网页上跟 AI 聊天，后来有了 Claude Code，但用的还只是少数独立开发者和工程师。对我来说，真正的转折点是 openclaw 的发布，从学生到老人，所有人都开始用这种 agent，token 的需求比以前大得多。虽然现在已经几乎没人聊 openclaw 了，但我觉得它开启了 AI 的一个新历史阶段，让更多人进入了 agent 时代。

第三个维度是算力资源的短缺。token 的需求可以指数级增长，推理能力不行，它正在成为便宜 AI 的另一个约束。第一个证据是 DeepSeek 的高峰期定价：北京时间 09:00-12:00 和 14:00-18:00，它的价格会是平常的两倍。如果 DeepSeek 只是觉得自己成本太高，它完全可以把全天的价格都涨上去，但实际情况更像是在做需求整形——用价格把弹性负载从推理能力稀缺的时段挪开。

OpenCode 的公开数据说明了需求变化能有多快。它的日 token 用量从 6 月底的大约 3 万亿涨到了 8 月 14 日的 22 万亿。这些 token 并不全都代表新的计算量，因为 agent 工作负载的缓存命中率非常高，但这个增长仍然说明，agent 型负载能多快地把压力传导到推理基础设施上。
